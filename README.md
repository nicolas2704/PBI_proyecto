# PBI-PROYECTO
Proyecto de Ingenieria de Datos sobre los paises y sus respectivos PBI. Este proyecto esta diseñado para ser ejecutado en el orquestador de Aiflow y el archivo .py principal, llamado: PBI_github.py, es necesario para su funcionamiento que las variables de entorno sean cargadas. Por tema de seguridad no subo dichos datos ya que son privados e incluyen contraseñas. Al ejecutar el DAG en Airflow, lo que realiza es un web scraping de etiquetas web de una pagina que dispone de 215 paises y sus respectivos PBI. Se realiza una extraccion de dichos datos y una transformacion de los mismos para quitarle las inconsistencias presentes. Hay disponible un archivo xlsx los cuales se pueden observar los datos sin tranformar llamado: Paises_PBI_extraidos.xlsx y otro que posee los datos limpios llamado: Paises_PBI_transformado.xlsx.
Para finalizar se realiza una carga de los datos en una base de datos relacional en PostgreSQL para que puedan ser utilizados en la creacion del Dashboard de Power BI disponible como: PBI_paises-pbix.
El proceso posee un archivo de registro el cual indica fecha, hora y descripcion de cada tarea realizado durante el pipeline en un archivo llamado: etl_proyect_log.txt
